# Git rules
- NEVER commit and/or push changes on your own!

# C# documentation rules
- Never change code when documenting
- Only document code with the 'public' access-modifier
- Indent tags
- Never remove lines
- Do not return example code, do not use @author or @version or @since tags. 
- DO NOT generate example usage.
- DO NOT generate usage example.
- DO NOT use html tags such as <p>, <lu>, <li>, <strong>.
- DO NOT generate documentation for type member properties.
