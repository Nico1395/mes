# Git rules
Following rules are NEVER to be broken when using git:
- NEVER commit and/or push changes on your own!

# C# documentation rules
Following rules are NEVER to be broken when documenting C# code with comments:
- NEVER change the actual code for documentations
- ONLY document code with the 'public' access-modifier
- NEVER add a reference to an abstraction's implementation in it's documentation
- ALWAYS indent comment tags with 4 spaces
- NEVER remove lines
- NEVER add examples
